# ProfitLab AI — responsive static demo

A no-server HTML/CSS/JavaScript prototype for a business analytics hackathon project.

## Run locally
1. Extract the ZIP archive.
2. Open `index.html` in a modern browser.
3. Press **Open demo / Открыть демо** and upload a CSV, or download the sample CSV.

## CSV format
Recommended columns: `product,quantity,price,cost`.
- `product`: product name
- `quantity`: number of units sold
- `price`: selling price per unit
- `cost`: cost per unit

The demo calculates revenue, estimated costs, profit, overall margin, groups rows by product, flags loss-making products, and shows the lowest-margin products. Data is processed locally in the browser; no server or database is used.

## Languages
Russian, Kazakh, and English. The selection is saved in the browser.

## Important
This is a static MVP prototype. Recommendations are rule-based calculations, not generated by an external AI model. Sample dashboard figures are illustrative until a CSV is uploaded.
